# Legacy Worker (behavior reference)

`worker.js` is the exact production Worker bundle as deployed on 2026-09-29
(version `2e7b163e`: the 0.6.8-era code plus the admin-header hotfix).
It was downloaded from Cloudflare, not built from this repo.

It is the oracle for the rewrite: `test/record-golden.mjs` runs the scenarios in
`test/scenarios.mjs` against it and records `test/golden/*.json`. The new Worker
must reproduce those results for every public `/api/v1` route, so that addon
versions already in players' hands keep working. Do not edit this file.
